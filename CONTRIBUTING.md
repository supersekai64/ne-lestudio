# Contribuer

- **Branches** : en anglais, concises, `features/<subject>` ou `fix/<subject>` (ex. `features/accent-color-picker`).
- **Commits** : en anglais, concis, commencent par `feat:` ou `fix:` (ex. `feat: add accent color picker`).
- **Description de PR** : en français, liste à puces de ce qui est fait, rien d'autre.
- **Validation** : toute PR doit être validée par quelqu'un d'autre que son auteur avant fusion.
- **Versions** : respecter les versions en place ; les mettre à jour pour une raison de sécurité ou de pertinence technique.
- **Sécurité** : aucune clé ni secret dans le dépôt, aucune faille introduite.

Exemple de description :

```
- Ajoute le choix de la couleur des encadrés (date, source) dans l'éditeur
- Corrige le texte du modèle événement qui débordait en format story
```
